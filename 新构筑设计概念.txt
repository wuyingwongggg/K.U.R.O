新构筑设计概念

machine    热量表：攻击和移动时累计热量，按下核心技能键清空当前获取的全部热量，根据消耗的热量提升接下来一段时间的攻击伤害。    分支：热量累积强化、热量释放强化
waiter    药剂：每过N秒后获取一针药剂，按下核心技能键消耗一针药剂恢复血量。    分支：血量回复强化、血量扣除强化
throw    投掷：进入投掷状态时显示指示器（MainCharacter.HitboxEditorPreview），按下核心技能键在指示器位置生成一个一次性家具。    分支：投掷类武器强化、投掷类家具强化

三个职业现在的结构很清晰，先整理对齐再展开：

```
Machine  热量积累→释放爆发    热量累积强化 / 热量释放强化
Waiter   被动等待→主动消耗    血量回复强化 / 血量扣除强化
Throw    指示器瞄准→生成道具  投掷类武器强化 / 投掷类家具强化
```

三个职业的二元构筑分类形成了很好的对称结构，每个职业内部两个流派互相对立，玩家要在同一个核心机制的两种用法之间选择方向。


**六个流派完整设计**

---

### Machine · 热量累积强化

**核心思路：让热量积累本身产生效果，不依赖释放**

```
热量在积累过程中每达到一定阈值触发效果
不按主动技能键，让热量自然溢出时触发溢出奖励
热量越高时攻击附加额外机制

代表效果
  热量每积累25点，下一次攻击附加固定0.5秒
  热量达到上限自动溢出时，触发全场减速3秒
  热量高于50时，攻击命中使目标减速（热量越高减速越久）
  停止移动时热量不衰减，允许蓄满后再行动
```

**玩法感觉**
```
不急着按主动技能
让热量自然积累产生持续收益
溢出是奖励而不是惩罚
耐心积累，靠阈值机制持续控场
```

---

### Machine · 热量释放强化

**核心思路：最大化主动技能释放时的爆发效果**

```
主动技能消耗的热量越多，释放后的强化效果越强
围绕「什么时候按、积累多少再按」做决策
释放后有额外触发条件

代表效果
  消耗热量>75时，释放后攻击使目标击晕1秒（高热量奖励）
  释放后的强化持续时间与消耗热量成正比
  主动技能CD缩短：每次释放后根据消耗热量减少下一次CD
  释放瞬间对周围敌人产生冲击（消耗热量越多范围越大）
```

**玩法感觉**
```
尽量积满再释放
主动技能是核心操作节奏
追求每次释放的价值最大化
爆发型，有明显的输出峰值和平静期
```

---

### Waiter · 血量回复强化

**核心思路：围绕药剂和治疗建立滚雪球机制**

```
治疗触发额外效果
持有药剂数量越多产生被动收益
治疗量与战斗状态联动

代表效果
  使用药剂后3秒内受到的下一次伤害完全无效
  持有3瓶药剂时（满瓶）攻击附加额外固定效果
  血量越低时药剂治疗量越高（紧急时更有效）
  药剂使用后立即开始生成下一瓶，不等满瓶CD
```

**玩法感觉**
```
保证自己有药可用
满瓶状态维持被动收益
低血量时反而更强
生存能力极强，适合硬打
```

---

### Waiter · 血量扣除强化

**核心思路：主动消耗血量换取强化状态，血量是资源**

```
长按主动技能键消耗血量而不是药剂触发强化
血量越低时强化效果越强
药剂从治疗工具变为「维持生命线」的保障

代表效果
  长按1秒消耗5点血量，进入强化状态（攻击固定效果延长）持续5秒
  强化状态期间受到的伤害减半（以血换防）
  血量低于25%时强化状态自动触发无需消耗
  药剂不治疗，改为延长当前强化状态持续时间
```

**玩法感觉**
```
故意维持低血量
药剂是强化续航而不是保命
高风险高回报
需要精确判断何时扣血何时用药
```

---

### Throw · 投掷类武器强化

**核心思路：强化背包中持有的投掷武器，围绕弹药和命中效果**

```
主动技能生成的道具视为临时武器
投掷武器的弹道、命中判定、弹药回收强化
连续命中同一目标积累效果

代表效果
  投掷武器命中后自动回收弹药（下一发不需要手动补充）
  连续命中同一目标3次触发固定2秒
  主动技能生成的道具命中后等同于投掷武器补充1发弹药
  弹药耗尽时投出主动技能道具，命中效果翻倍
```

**玩法感觉**
```
弹药管理是核心
主动技能是应急补弹手段
连续命中同一目标有奖励
适合精准打法，每发都要命中
```

---

### Throw · 投掷类家具强化

**核心思路：强化场景家具和主动技能生成的道具，围绕区域控制**

```
主动技能生成的道具视为家具
家具命中后产生区域效果而不是单体伤害
家具数量和生成速度强化

代表效果
  家具落地后产生碎片区域（踏入减速2秒），持续时间延长
  主动技能CD缩短：每次家具命中敌人减少2秒CD
  主动技能生成的道具落地后分裂成多个小型碎片散射
  场景内同时存在3件家具道具时触发连锁：所有道具同时对最近敌人产生固定
```

**玩法感觉**
```
布置战场，用家具控制敌人走位
主动技能频率是核心
扔的不是单点伤害而是区域封锁
适合多敌人场景，群控流
```

**三职业六流派总览**

| 职业 | 核心资源 | 主动技能 | 流派A | 流派B |
|---|---|---|---|---|
| Machine | 热量Heat | 清空热量→短暂强化 | 热量累积强化（阈值触发）| 热量释放强化（爆发最大化）|
| Waiter | 药剂Vial | 消耗药剂→回血 | 血量回复强化（治疗联动）| 血量扣除强化（以血换强）|
| Throw | 指示器（HitboxEditorPreview） | 生成一次性家具 | 投掷武器强化（弹药循环）| 投掷家具强化（区域控制）|

**三职业差异化定位：**
```
Machine  爆发型  积累→释放，有明显的峰值和平静期
Waiter   生存型  围绕血量做决策，极限操作空间大
Throw    控场型  布置战场，靠区域效果和连续命中控制节奏
```
